FASTEST GITHUB PAGES ROUTE
1. Create a public GitHub repository named: portfolio
2. Upload index.html, Chaehyun_Lim_Resume.pdf, and the assets folder to the repository root.
3. In the repository, open Settings -> Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Select branch "main" and folder "/ (root)", then Save.
6. GitHub will show the live URL after deployment.

Typical URL format:
https://<your-github-username>.github.io/portfolio/

Use that live URL in the application field labeled "Please include a link to your portfolio below".
